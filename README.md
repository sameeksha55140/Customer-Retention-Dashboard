🏦 Customer Engagement & Product Utilization Analytics for Retention Strategy

📌 Project Overview

This project analyzes customer engagement and product usage patterns to understand **bank customer retention behavior**.
Instead of relying only on demographics, this analysis focuses on **behavioral signals like activity, product adoption, and financial engagement** to identify churn risk.

---
🎯 Objectives

* Analyze the relationship between **customer engagement and churn**
* Evaluate how **product usage impacts retention**
* Identify **high-value but disengaged customers**
* Build a **data-driven retention strategy framework**

---

 📊 Dataset Description

| Column          | Description                      |
| --------------- | -------------------------------- |
| CustomerId      | Unique customer ID               |
| Surname         | Customer name                    |
| CreditScore     | Credit score                     |
| Geography       | Country (France, Spain, Germany) |
| Gender          | Male/Female                      |
| Age             | Customer age                     |
| Tenure          | Years with bank                  |
| Balance         | Account balance                  |
| NumOfProducts   | Number of bank products          |
| HasCrCard       | Credit card ownership            |
| IsActiveMember  | Activity status                  |
| EstimatedSalary | Annual salary                    |
| Exited          | Churn (1 = Yes, 0 = No)          |

---

 🧠 Key Concepts Used

* Customer Segmentation
* Engagement Analysis
* Product Utilization Analysis
* Churn Analysis
* KPI Design

---

 📈 Key Insights

* Active customers show **significantly lower churn**
* Customers with **multiple products are more loyal**
* High balance customers can still churn if **disengaged**
* Engagement is a **stronger predictor than income**

---

 🧮 KPIs Implemented

* Engagement Retention Ratio
* Product Depth Index
* High-Balance Disengagement Rate
* Credit Card Stickiness Score
* Relationship Strength Index (RSI)

 ▶️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/sameeksha55140/Customer-Retention-Dashboard.git
```

2. Navigate to folder:

```bash
cd Customer-Retention-Dashboard
```

3. Install dependencies:

```bash
pip install streamlit pandas plotly
```

4. Run the app:

```bash
streamlit run app.py
```
